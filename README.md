# ForceTech_SQDigital
SQDigital, lembaga pendidikan Islam dengan unit TPA, TKIT, dan Metode Qur'an Tilawati (±60 karyawan, 15 pengajar), membangun SIM SDM terpusat untuk mengatasi proses manual. Empat modulnya: Rekrutmen, Presensi dan Cuti, Penggajian, serta Kinerja Pengajar. Hasil: proses lebih cepat, perhitungan akurat, penilaian objektif, dan keputusan berbasis data.
